## 📁 Featured Portfolio Work

### 🏛️ [governance-grc-labs](https://github.com/SCGLabs/governance-grc-labs)

Governance, Risk and Compliance projects — ISO 27001 implementation artefacts, risk assessments, audit documentation, and compliance case studies.

| Project | Description |
|---|---|
| `iso27001-isms-implementation` | End-to-end ISMS implementation for a simulated 30-person SaaS organisation — scope, risk assessment, SoA, and management review |
| `risk-register-template` | Structured risk register with likelihood/impact scoring, treatment actions, and residual risk tracking |
| `statement-of-applicability` | All 93 Annex A controls assessed with documented applicability decisions, including the 11 new 2022 controls |
| `internal-audit-evidence-pack` | Audit evidence package covering documentation review, control validation, and findings |
| `corrective-action-log` | Template and example corrective action tracking aligned to ISO 27001 Clause 10 |
| `gap-analysis-report` | ISO 27001:2022 gap analysis template with prioritised remediation mapping |

Azure and AWS security fundamentals — identity, access, logging, monitoring, and cloud security governance labs.
